# Content Review

## 审校目标

本文件记录 1.0 候选版的题目和结果文案审校结论。目标是确保内容自然、克制、适合中文用户，并符合产品边界：

- 不使用受保护的人格测试名称或表达。
- 不模仿人格类型测试。
- 不进行医学、心理、法律或职业诊断。
- 不承诺科学测量结论。
- 不把结果写成固定身份或终身标签。

## 题库审校

当前题库：

- 总题数：48。
- Mind / 认知：12 题。
- Body / 身体：12 题。
- Spirit / 意义：12 题。
- Vocation / 事业：12 题。
- 反向计分题：12 题，每个象限 3 题。

审校结论：

- 题干整体为中文日常表达，没有论文式或临床式措辞。
- 题目围绕自我理解、生活系统和行动习惯，不做疾病、障碍或人格诊断判断。
- 反向题分布均衡，可降低机械作答风险。
- Body 题目使用“精力、作息、恢复、身体活动”等发展性表达，避免把身体状态写成健康诊断。
- Spirit 题目聚焦价值、欲望、方向和外部评价驱动，避免宗教化或玄学化表达。
- Vocation 题目聚焦能力、作品、反馈和价值转化，避免承诺收入或职业成功。

## 32 题候选版内容审校

2026-07-05 已完成 32 题平衡版内容候选设计；用户随后取消全部准确性研究。当前状态为 `unvalidated draft / indefinitely paused`，不访谈、不配对、不复测、不招募、不公开，48 题仍是生产基准。

候选内容规格见 `docs/QUESTION_BANK_32_CONTENT_SPEC.md`，其中包含：

- 现有 48 题的保留、改写、移出矩阵。
- 每象限 8 题的工作候选和 2 道反向题。
- Spirit 关系连接、Mind 情绪与信念觉察、Body 身体在场、Vocation 资源系统的新题候选。
- 32 题入口、结果确定性、并列象限、免责声明和分享卡片口径。
- 已取消的 48/32 配对与历史晋级门槛，仅作 archive/optional reference。

内容审校结论：

- Mind 的注意、清晰、专注存在重复，证据核验和自我修正有社会期许风险。
- Body 的精力觉察、延迟恢复、基础维护存在重复；深度工作时段和环境整理属于间接代理。
- Spirit 的方向、外部认可和内在判断重复最多，也是缩题后最容易失真的象限。新增一个关系题只能补可获得连接，不能代表共同体、服务和超越。
- Vocation 的产出、价值和反馈存在重复，部分题目偏创作者、知识工作者或高自主岗位。
- 反向题候选控制为每象限 2 道，删除羞耻词、绝对词和明显正确答案；反向题不是测谎题。

当前没有 32 题晋级或默认切换路径，也没有任何准确性通过结论。只有用户未来重新明确授权时，才重新制定验证方案；在此之前继续使用 48 题。

## 结果文案审校

审校范围：

- `data/result-templates.json`
- `data/recommendations.json`
- `data/site-content.json`
- 结果页展示组件中的固定标题
- 分享卡片底部说明

审校结论：

- 结果文案以“当前状态快照”为主，不把用户固定成某类人。
- Core Problem 聚焦当前系统卡点，不使用绝对化或恐吓性表达。
- Cross-Quadrant Dynamics 解释象限互动，避免神秘化。
- Immediate Next Action 和 7/30/90 天建议具体可执行，不承诺治疗、治愈、财富或职业结果。
- 分享卡片保留记忆点，但底部明确“不是人格标签”。

## 仍可进行的非准确性检查

1. 不再组织真实用户或产品团队样例复核阶段阈值；既有模拟画像只属于内部工程/产品检查，不是实证准确性证据。
2. 用户已取消准确性研究和相关招募；原 3 到 5 人反馈计划仅作 archive/optional reference，不再执行。
3. 按 `docs/MOBILE_QA_CHECKLIST.md` 用手机浏览器检查分享卡片下载和社交平台展示效果。
4. 检查英文 Metatype 对中文用户是否有帮助；如果理解成本高，可在 1.1 改为中英文并列。

当前内容达到 1.0 候选版的内部内容审校标准。用户已取消小样本反馈、阈值复核和相关招募；这些不再是发布前置，也不能被视为已经通过。
