# 32 题候选版认知访谈记录模板

> 状态：`archived-cancelled`。产品已取消认知访谈和准确性研究；不得继续收集记录。文末 `cognitive_pass` 仅为历史字段，当前不适用。

## 使用说明

- 状态：`optional / archived-reference`。用户已取消访谈、配对、复测和招募，本模板不进入当前执行路径。
- 只有用户未来重新明确授权时，才可复制本模板开展研究。
- 仅记录匿名产品研究信息。
- 内容快照必须填写，默认 `h3-a32-v1-cog-r1`。
- 原话放在引号中；研究员判断使用标准标签。
- 保留本模板不代表访谈已经完成、必须完成或准确性已经验证。

## 编码规则

| 字段 | 取值 |
| --- | --- |
| 理解复述 | 写受访者原话；另标 `match / partial / misread`。 |
| 犹豫 | `0` 无明显犹豫；`1` 需要短暂停顿或二选一；`2` 无法稳定判断题意/答案。 |
| 词义歧义 | `0` 无；`1` 有词需确认；`2` 同一词产生与目标构念不同的稳定理解。 |
| 双重问题 | `no / possible / yes`；记录用户认为混在一起的两件事。 |
| 角色不适用 | `no / partial / yes`；记录造成不适用的默认角色或情境，不记录敏感原因。 |
| 社会期许 | `0` 无；`1` 感到某答案更体面；`2` 明确认为题目要求“正确/成熟”答案并影响作答。 |
| 近 4 周可回忆性 | `2` 能立即举例；`1` 只能给宽泛印象；`0` 无法用近 4 周经历回答。 |
| 建议改写 | 尽量记录用户原话；没有则留空。 |

稳定误读：受访者在没有主持人解释的情况下，把题目复述成另一个构念，并在追问后仍保持该理解。

| candidate_id | valid_n | stable_misread_n | hesitation_2_n | ambiguity_2_n | double_yes_n | role_yes_n | role_yes_pct | social_2_n | recall_0_n | decision | next_snapshot | reason |

## 通过、修订和淘汰规则

### Pass

完成至少 8 人后，同时满足：

- 稳定误读少于 2 人。
- `role_yes_n / valid_n < 25%`。
- 没有明显诱导；`social_2_n` 少于 2，且内容评审未确认结构性正确答案。
- 没有 2 人及以上指出同一双重问题或同一关键歧义。
- `recall_0_n / valid_n < 25%`。
- 题目仍覆盖预定构念，且没有通过扩大结果解释弥补题干不足。

### Revise

满足任一条件必须修订，并创建新候选快照：

- 同一题有 2 人及以上出现同方向的稳定误读。
- 角色不适用比例达到或超过 25%。8 人中 2 人、9–11 人中 3 人、12 人中 3 人即触发。
- 题目存在明显诱导：2 人及以上明确指出同一“正确/成熟答案”，或内容评审确认题干本身带审判、羞耻或绝对价值暗示。
- 2 人及以上指出同一双重问题或关键词歧义。
- 近 4 周不可回忆比例达到或超过 25%。
- 主持人需要反复解释构念，用户才能作答。

修订后：

1. 不覆盖原题干。
2. 快照从 `h3-a32-v1-cog-r1` 升为 `r2`、`r3` 等。
3. 记录修改原因和受影响题号。
4. 新题干重新访谈，旧快照数据不能与新题干合并计算通过率。

### Remove / Swap

满足任一情况进入淘汰或预登记交换位评审：

- 同一题经过一轮明确改写后仍再次触发相同修订规则。
- 降低社会期许或角色偏差后，题目已无法稳定表达目标构念。
- 与另一候选高度重复，且删除后不损害核心覆盖。
- 题目只适用于少数角色，而该限制不是目标构念本身。
- 为保住 32 题而继续保留会造成关键构念失真的题。

淘汰或交换由产品、内容、模型共同确认。若交换导致核心覆盖下降，回退 48 题或增加题量，不以缩短为优先。

## 研究阶段结论

最终报告只能使用以下状态：

- `prepared`：材料准备完成，尚未访谈。
- `in_progress`：已开始访谈，样本未满或仍在分析。
- `revision_required`：有题目触发修订规则。
- `cognitive_pass`：仅供未来重新授权可选研究时使用；当前不是任何晋级前置条件。
- `stopped`：核心覆盖或可理解性无法在 32 题内成立，停止短版并保留 48 题。

`cognitive_pass` 不等于 32 题准确、稳定、可公开或可替代 48 题；当前产品路径不再追求该状态。
